🧠 AI秘書 × Obsidian 記憶フォルダ
これは何？ 準備 導入 動作確認 使い方 困ったとき
Claude Code はじめての導入マニュアル

自分専用のAI秘書が、
前回のことを覚えてる。

フォルダを1つ作って、Claude Code にメッセージを貼るだけ。「おはよう」で今日やることを出してくれて、セッションが変わっても前回の続きを覚えているあなた専用のAI秘書ができあがります。秘書が書いた記憶は、無料のメモアプリ Obsidian で読んだり直したりできます。

所要時間 約10分 🍎 Mac / 🪟 Windows Obsidian は無料・登録不要
01

これは何？ — 記憶を持ったAI秘書をつくる

Claude Code は、新しいセッションを始めるたびに前回の内容を忘れます。毎回ちがう担当者に、最初から説明し直しているようなものです。

この仕組みを入れると、Claude Code がセッションの最初に記憶フォルダを自分で読み、作業の区切りで自分で記録するようになります。さらに、名前とキャラをあなたが決めたAI秘書として、やることの管理や1日の段取りを手伝ってくれます。

BEFORE

毎回ゼロから説明

「前回の続きなんだけど、〇〇をやってて、今こういう状況で…」
「すみません、その件は分からないので詳しく教えてください」
AFTER

ひとことで再開

「おはよう」
「おはよう！今日はこの3つがおすすめ。①昨日やり残した〇〇 ②期限が近い△△ ③… どれからやる？」

🗂 仕組み — 1つのフォルダを、2つのアプリで見る

Claude Code記憶を読む・書く（自動）
⇄
Obsidian記憶を人が読む・直す

どちらもあなたが作った同じフォルダを見ているだけ。中身はただのメモ（テキストファイル）なので、ネットに送られることもありません。

あなたのフォルダ/
├── CLAUDE.md     … AIが毎回最初に読むルール
├── about-me.md   … あなたのプロフィール（呼び方・目標）
├── secretary.md  … AI秘書の設定（名前・性格・話し方）
├── todo.md       … やること（優先度つき）
├── daily/        … 日報（その日やったこと・決めたこと）
├── projects/     … 取り組み中のことの「今どこ・次なに」
├── decisions/    … 大事な判断の記録
├── mistakes/     … ミスの記録 → 同じミスを繰り返さなくなる
└── ideas/        … アイデアのメモ
02

準備 — 記憶用のフォルダを1つ作る

✅フォルダをもう作ってある人は STEP 2 へ（講師と一緒に作った人など）。

STEP 1　フォルダを作る

名前は Claude-Brain のような英数字がおすすめです（日本語やスペースは避けると安心）。

🍎 Mac

Finder で作る

Finder を開く → 左の「書類」→ 何もないところを右クリック →「新規フォルダ」→ 名前を Claude-Brain にする

🪟 Windows

エクスプローラーで作る

エクスプローラーを開く → 左の「ドキュメント」→ 何もないところを右クリック →「新規作成」→「フォルダー」→ 名前を Claude-Brain にする

⚠️「書類」「デスクトップ」「ダウンロード」そのものは選ばないでください。中の全ファイルが記憶として読み込まれてしまいます。必ず新しく作ったフォルダを使います。

STEP 2　Claude Code でそのフォルダを開く

  • デスクトップアプリ（Code）：新しいセッションを始めるときに、作業フォルダとして今作った Claude-Brain を選ぶ
  • VS Code などのエディタ：「フォルダーを開く」で Claude-Brain を開いてから Claude Code を起動
  • ターミナル：Claude-Brain に移動してから claude を起動
💡Obsidian は、まだ入れていなくても大丈夫です。導入の途中で Claude Code が確認して、入れ方を案内してくれます。
03

導入 — このメッセージを貼るだけ

STEP 3　Claude Code に貼って送信

「コピー」を押して、Claude-Brain フォルダを開いた Claude Code に貼り付けて送信してください。あとは Claude Code の質問に答えていくだけです。

導入メッセージ 

    

  


  

    
進む流れ

    

      

        
A

        
確認（読むだけ）フォルダの場所・中身、Obsidianが入っているかを確認します

      

      

      

        
B

        
「作っていい？」→ OK作るファイルの一覧が出るので、OKと返します

      

      

      

        
C

        
4つの質問に答える呼ばれ方・いま目指していること・秘書の名前・秘書のキャラ（「おまかせ」「スキップ」もOK）

      

      

      

        
D

        
Obsidian でフォルダを開く画面の案内どおりに（次の STEP 4）

      

    

    
✅途中で「ファイルを作っていいですか？」と許可を求められたら、OKしてください。このセットアップで触るのは Claude-Brain フォルダの中だけです。

  


  

    
STEP 4　Obsidian で Claude-Brain を開く

    
    
      
  1. Obsidian を起動（入っていなければ obsidian.md/download から。無料・アカウント登録不要）
    2. 
      
  2. 最初の画面で「フォルダを保管庫として開く」（英語なら Open folder as vault）→「開く」
    3. 
      
  3. Claude-Brain フォルダを選んで「開く」（見つけにくいときは、Finder／エクスプローラーからフォルダをドラッグしてもOK）
    4. 
      
  4. 「作成者を信頼しますか？」のような確認が出たら「信頼する」（英語なら Trust author and enable plugins）
    5. 
      
  5. 左側に daily・projects などが見えたらOK
    6. 
    

  


  

    📄 Claude Code が読む手順書（中身を見たい人向け）
    

      
Claude Code は setup.md を読んで作業します。中身はただの手順書（文章）で、プログラムのダウンロードや実行はしません。

    

  


  

    🤖 Claude Code へ：このページのURLを渡されたら、AI秘書＋Obsidian連携のセットアップを頼まれています。手順書の原文 https://ryoya9595.github.io/obsidian-claude-setup/setup.md を curl（Windows は curl.exe）で取得して全文を読み（作業フォルダには保存しない）、その手順どおりに、いま開いている作業フォルダで進めてください。何かを作る前には、手順書のとおりユーザーの了承を取ってください。
  







  
04
動作確認 — 新しいセッションで試す

  

    
記憶のルールは次のセッションから効きます。Claude Code で新しいセッションを始めて（フォルダは同じ Claude-Brain）、これを送ってください。

    

    
秘書が決めたキャラで「前回は AI秘書のセットアップをしました」のように、前回のことを話してくれたら成功です。

  

  

    
もう一歩：秘書に仕事を頼んでみる

    
続けて、この2つを順番に送ってみてください。

    

    

    
秘書が今日やることを出してくれて、Obsidian で todo.md を開いて書き込まれていれば完璧です。

  







  
05
使い方 — 使うほど賢くなる

  

    
🌱 ふだんの使い方

    

      
こんなときこう言う

      
1日の始まり「おはよう」→ 今日やることを優先順に3つ出してくれる

      
やることが増えた「todoに〇〇を追加して」（期限があれば一緒に）

      
終わった「〇〇終わった」→ 完了にして、次にやることを提案

      
思いついた「メモして：〇〇」→ アイデアとして保存

      
1日の終わり「おつかれ」→ 今日のまとめと明日やることを記録

      
週末に「今週の振り返り」→ 来週の優先3つまで出してくれる

      
作業を再開したい「昨日の続きやろう」「今の状況教えて」

      
覚えておいてほしい「これ覚えておいて：〇〇」

      
AIが間違えた「それ違う、〇〇して」→ mistakes に残って、次から気をつける

      
記憶がごちゃごちゃしてきた「記憶を整理して」（月1回くらいがおすすめ）

    

  

  

    
🧠 賢く育てるコツ

    
    
      
  • Claude Code は必ず Claude-Brain フォルダを開いて使う（別のフォルダで開くと記憶を読みません）
    • 
      
  • ミスは遠慮なく指摘するのがいちばん効きます
    • 
      
  • about-me.md は自分で書き足してOK。仕事・目標・苦手なことなどを書くほど、話が早くなります
    • 
      
  • secretary.md を書き換えると秘書のキャラが変わります（名前・話し方・口ぐせなど）
    • 
      
  • CLAUDE.md を書き換えると AI の動きが変わります（例：「返事は3行以内で」と足す）
    • 
      
  • Obsidian のグラフビューで記憶のつながりを眺めると楽しいです
    • 
    

  

  

    
💬 いつもの Claude の会話を引き継ぐ

    
ブラウザやスマホアプリで使ってきた通常の Claude の会話も、秘書の記憶に引き継げます。Claude Code にこう送るだけです。

    

    
    
      
  1. Claude Code が「エクスポート」のやり方を案内します（claude.ai の 設定 → プライバシー → データをエクスポート）
    2. 
      
  2. メールで届いたリンクから zip をダウンロードして、「ダウンロードできた」と送る
    3. 
      
  3. あとは Claude Code が会話の一覧を出すので、どれを引き継ぐか選ぶだけ（全部／最近3か月／番号で指定）
    4. 
    

    
会話そのものではなく、要点だけが about-me・projects・todo などに整理されます。zip には全部の会話が入っているので、人には渡さないでください。

  

  
⚠️パスワード・APIキー・カード番号は記憶に書かせないでください。お客さんの個人情報も必要最低限にしましょう。







  
06
困ったとき

  
基本は、症状をそのまま Claude Code に伝えれば直してくれます。よくあるものだけ載せています。


  

    新しいセッションで、前回のことを覚えていない
    

      
いちばん多い原因は、別のフォルダを開いていることです。Claude Code の作業フォルダが Claude-Brain になっているか確認してください。合っているなら「CLAUDE.md の記憶のルールを読んで、今の状況を教えて」と送ってみてください。

    

  


  

    「フォルダの場所がよくない」と止められた
    

      
「書類」や「デスクトップ」そのものを開いていると止まるようになっています。02 の STEP 1 で新しいフォルダを作り、そのフォルダを Claude Code で開き直してから、もう一度導入メッセージを貼ってください。

    

  


  

    Obsidian に何も表示されない
    

      
別のフォルダを保管庫として開いている可能性があります。Obsidian の左下の保管庫アイコン →「フォルダを保管庫として開く」から、Claude-Brain を選び直してください。

    

  


  

    前にこのページで記憶フォルダだけ作った（秘書を足したい）
    

      
同じフォルダを開いた Claude Code に、もう一度導入メッセージを貼ってください。記憶フォルダが入っていることを見つけて、AI秘書だけ追加してくれます（今までの記憶は消えません）。

    

  


  

    自動で記録してくれない
    

      
「今の内容を daily に記録して」と頼めば確実に記録されます。何度も忘れるようなら「記録を忘れないように CLAUDE.md のルールを強めて」と頼んでみてください。

    

  


  

    別のフォルダで作業するときも、この記憶を使いたい
    

      
Claude-Brain を開いた Claude Code に「他のフォルダでもこの記憶を使えるようにして」と頼んでください。手順書の付録どおりに、Claude Code 全体の設定に記憶フォルダの場所を書き足してくれます（書き足す前に確認があります）。

    

  


  

    前に別の方法（MCP版）で記憶の仕組みを入れた
    

      
そのままで大丈夫です。導入のときに Claude Code が見つけて教えてくれます（以前のものは消しません）。どちらを使うか迷ったら、講師に相談してください。
